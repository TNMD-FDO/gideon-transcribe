Phase 5 · chapter 2 · drawn 2026-10-23 · for the maintainer's word

An Admin keeps a voice for any unit, or for several

The maintainer's ask of 2026-10-23: as an Admin, add a voice to any unit they choose, whatever unit the case or the Admin is in. Everyone else keeps as now, into the case owner's unit only. Three places change: the Keep button on the case's Speakers tab, the kept card and its menu, and the chain on the Voices place. The names are the fictional office's.

What everyone else sees on the same card is unchanged: Keep for the Appeals..., their own unit, when the case's owner is in one; nothing when the owner is in no unit.

The confirm box

Keep Tony Marsh's voice for a unit?

Tick the units whose voice book takes this print. This case's unit is ticked first.

Each book gets the print as it stands and learns from this case as it is checked. Stop keeping, per unit, is in the card's menu.

Who sees it. Only an Admin gets the chooser. The units are the Panel's Units lines, in that order; the case owner's unit is ticked when there is one, otherwise nothing is ticked and the Admin ticks what they mean. The button counts the ticks: "Keep for 2 units".

The case owner in no unit no longer stops an Admin: the chooser lists every unit anyway. So an Admin who owns a test case, and is in no unit themself, keeps straight from it. Non-admins still need the owner in a unit, as the chapter says.

The rules that stay. The person needs a print and a kept role (Officer, Interpreter, Interviewer on the office's server); a client's side or a witness is never offered, to anyone. Keep voices for the unit must be on.

The same card for everyone else reads "Kept for the Appeals unit, for a unit you are not in", or theirs with Stop keeping, as now.

Also keep for. One line per unit that does not yet hold the voice. It needs no confirm box of its own: the chain changes at once and an audit row says which unit. The print copied is the person's as it stands today.

Stop keeping, per unit. One line per unit that holds it. Stopping the last one marks the person not kept, as today; the book forgets the voice when no other case teaches it. The person's own print stays in every case.

Teaching. Every book that holds this person's share is taught by this case's checks, not only the owner's unit's. The chain says "teaches both books" or "teaches 3 books".
