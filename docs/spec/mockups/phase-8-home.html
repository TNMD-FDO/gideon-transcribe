What it gives: the left column is the old Start page's three doors with their full captions, so a new person reads what each thing does; the right column is where things are, with their states. The bar's two buttons are the same actions, so a person who has learned them never needs the cards again. What to judge

Whether the captions should always show (D and F) or live beside the places (E). Whether Home should lead with "what needs you" (E) or with the places in a fixed order (D, F). Whether the rail is worth changing every page's frame for. All three keep the same bar buttons, the same cases rows and the same session rows, so the pick changes the frame and the order, not the parts.
