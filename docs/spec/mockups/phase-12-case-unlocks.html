A case's tabs follow what the case holds: audio only, video, and a path file as the unlock

The ask of 2026-11-06: an audio-only case should carry only Recordings, Search, Notes, Speakers, Clips and Details, with no map; Add path files should be offered only once a video is in the case; the Map tab and everything that goes with it should appear only once the case has at least one valid path file, so a valid path file is a feature unlock for the case. Below: the three states as case bars, where every piece of the map feature shows today and the rule it would follow, and the choices. The fictional office throughout.

The Map tab appears with its count, the pill on Home and the case page, the desk's small map, an incident's Map pane, Save a picture, Within a circle, the near marks, the readings told to Gideon and the memo: the whole feature set, as today.

What decides a state. Audio only: no recording in the case has a picture (the probe's video stream, as the Incidents tab already judges it). Video: at least one has. The unlock: at least one recording of the case has a path file that was read (a Path row). A path file waiting for its video (chapter 6) does not unlock: it belongs to no recording yet.

The Panel's switches stay the master. Maps off hides the Map tab everywhere as today; Documents off, Incidents off, Clips off, the assistant off likewise. The case's state only narrows further. A tab that is hidden still answers its address (choice 5), so an old link never breaks.

A case moves between states by itself. The first video added turns Add path files on; the first path file read turns the Map on; a recording removed or a path file removed turns them off again. No setting per case, nothing to press.

Most of the feature set is already gated per camera: a camera without a path file never shows On the map, a readings line or a map pane. The new rule is at the case level, and it reaches four things: the Map tab and page, Add path files, the desk's small map, and the audio-only tabs.

The build's recommendation: the three states as drawn, with one helper deciding them, and the Map tab, the Map page, Add path files, the desk's small map and the Incidents tab following it. On Proposed events and Documents the build says what it thinks (keep them: they work on words) and does as you say.

What this is not: no per-case setting, no new store, no migration. The Panel's switches stay the office's masters; the state is read from what the case holds and changes as recordings and path files come and go. A new word for the glossary: the case's holds (or "what the case holds"), if the name stands.
